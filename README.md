#  Athlete Performance Optimization Dashboard

This project is an industry-oriented Sports Data Analytics application developed using Streamlit. It integrates data analysis, visualization, and machine learning to evaluate athlete performance and provide actionable insights.

---

##  Features

- Interactive dashboard with sport and athlete filters  
- Key Performance Indicators (KPIs): Performance, Fitness, Efficiency, Consistency  
- Visual analytics (bar chart, scatter plot, box plot)  
- Machine Learning-based performance prediction  
- Dynamic insights and recommendations  

---

##  Technologies Used

- Python  
- Streamlit  
- Pandas  
- Plotly  
- Scikit-learn  

---

## Application Overview

The system enables users to:
- Analyze athlete performance across sports  
- Identify trends using visualizations  
- Predict performance using ML models  
- Generate recommendations for improvement
